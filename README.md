# AI Chatbot with Gemini

A full-stack AI chatbot built using React, Node.js, Express.js, and Google Gemini API.

## Features

- AI-powered chat using Gemini
- React frontend
- Node.js and Express backend
- Conversation history
- API rate limiting
- Error handling

## Technologies

- React
- Vite
- JavaScript
- Node.js
- Express.js
- Google Gemini API
